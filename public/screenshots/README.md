# Screenshots for the Australis OS website

Add genuine screenshots from a tested Australis development build, not mockups.

- `desktop.png` — the graphical session (ideally 1280 × 800 or larger)
- `terminal.png` — the command shell
- `boot.png` — the startup screen or kernel monitor

These images are optional. The homepage detects the exact file names at build time and shows clearly labelled illustrations while real images are unavailable.

Please mention the Australis OS build or commit and capture method in the pull request so the captions can accurately describe what users are seeing.
