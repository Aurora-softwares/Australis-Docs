# Welcome to Australis OS

Australis is an **experimental operating system** made from the ground up as an Aurora Softwares project. Its code is written in Hydrogen (Hylang), and it is currently being developed and tested primarily in QEMU.

You do not need to understand kernels or bootloaders to explore this site. Start with the big picture, then dive into the technical details whenever you feel ready.

## Find your way

- **[First steps](./getting-started/first-steps/)** — learn what you need and boot Australis in a virtual machine.
- **[Explore Australis](./getting-started/explore/)** — try the shell, discover what is implemented, and understand the current limitations.
- **[Questions and answers](./getting-started/faq/)** — plain-language answers about using and contributing.
- **[How it works](./architecture/overview/)** — the bootloader, kernel, storage, and applications.
- **[Development roadmap](./development/os-roadmap/)** — plans and progress; development pages may describe historical milestones.

:::caution[Still in development]
Australis is **not** a general-purpose, finished desktop OS. Virtual-machine testing is the recommended way to explore it. Hardware compatibility and release readiness are not yet established.
:::

## Want to help build it?

Take a look at the [building guide](./building/building/) and the [source repository](https://github.com/Aurora-softwares/Australis-OS). The [Hydrogen project](https://github.com/Aurora-softwares/Hylang-Compiler) provides the compiler used to build Australis.

The technical pages are retained from the project's original documentation. Because Australis changes quickly, check the latest **Development** branch and its tests before relying on implementation details.
