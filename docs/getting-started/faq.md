# Frequently asked questions

## Can I use Australis as my everyday operating system?

Not yet. Australis is an experimental system for learning, engineering, and testing.

## Is it based on Linux?

No. Australis is being built as a separate operating system, with its own bootloader and kernel.

## What is Hydrogen?

Hydrogen (Hylang) is the programming language and compiler used for the Australis codebase. See the [compiler repository](https://github.com/Aurora-softwares/Hylang-Compiler).

## How can I try it?

Build and run it in QEMU. The [first steps](./first-steps/) guide walks through the process.

## Where are the screenshots?

The website includes a gallery designed for real QEMU captures. Screenshots will appear as they are provided and reviewed, with captions explaining the build and what you are seeing. The current visual example on the welcome page is an illustration, **not a screenshot of the OS**.

## Where can I see what works right now?

Use the [Development branch](https://github.com/Aurora-softwares/Australis-OS/tree/Development), the [technical documentation](../architecture/overview/), and the [development project](https://github.com/orgs/Aurora-softwares/projects/3). Plans and documentation may lag behind the newest implementation.
