## A project in development

Australis is **not a finished desktop operating system**. Virtual-machine testing is recommended, and physical-machine support and release readiness are still under development. The documentation includes detailed engineering notes that may describe historical work. For current status, check the [Development branch](https://github.com/Aurora-softwares/Australis-OS/tree/Development).

The operating system and its documentation are part of [Aurora Softwares](https://github.com/Aurora-softwares). Want to explore the language behind the project? Visit [Hydrogen Docs](https://hylang.co.uk/).
